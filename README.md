# Distribuciones de probabilidad

Sitio con las propiedades, formas y usos de distribuciones de probabilidad, con gráficos interactivos.

**Ver el sitio:** https://msotocabezas.github.io/distribuciones-probabilidad/

No hay que descargar ni instalar nada: todo funciona en el navegador.

## Distribuciones disponibles

| Tipo | Distribución |
|---|---|
| Continua | [Normal](https://msotocabezas.github.io/distribuciones-probabilidad/continuas/normal.html) |

## Estructura

- `index.html`: portada con la lista y la tabla resumen.
- `continuas/`, `discretas/`: una página HTML por distribución.
- `assets/dist.js`: funciones numéricas y graficador compartidos.
- `assets/style.css`: estilos compartidos.

Para agregar una distribución, copia `continuas/normal.html`, cambia el contenido y las funciones del gráfico, y agrégala a `index.html` y a este README.

## Fuente

Contenido basado en el [Univariate Distribution Relationships](http://www.math.wm.edu/~leemis/chart/UDR/UDR.html) de L. Leemis.
