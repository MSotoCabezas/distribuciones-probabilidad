Distribución normal

La notación \(X \sim N(\mu, \sigma^2)\) indica que la variable aleatoria \(X\) sigue una distribución normal con media \(\mu\) y varianza \(\sigma^2\).

Parámetros y soporte

La distribución tiene dos parámetros: \(\mu\), con \(-\infty < \mu < \infty\), que fija la posición del centro, y \(\sigma > 0\), que fija la dispersión. El soporte es toda la recta real, \(-\infty < x < \infty\). Al mover \(\mu\) la curva se desplaza sin cambiar de forma; al aumentar \(\sigma\) se ensancha y su altura máxima baja, porque el área total siempre es 1.

Función de densidad

$$f(x) = \frac{1}{\sqrt{2\pi}\,\sigma}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \qquad -\infty < x < \infty.$$

La densidad es simétrica respecto de \(\mu\), alcanza su máximo \(1/(\sigma\sqrt{2\pi})\) en \(x = \mu\) y tiene puntos de inflexión en \(\mu \pm \sigma\).

Función de distribución acumulada

$$F(x) = P(X \le x) = \frac{1}{2}\left[1 + \operatorname{erf}\!\left(\frac{x-\mu}{\sqrt{2}\,\sigma}\right)\right], \qquad -\infty < x < \infty,$$

donde la función error es

$$\operatorname{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2}\,dt, \qquad \operatorname{erf}(-x) = -\operatorname{erf}(x).$$

Esta integral no tiene forma cerrada elemental. En la práctica se estandariza con \(Z = (X-\mu)/\sigma \sim N(0,1)\) y se usa \(F(x) = \Phi\big((x-\mu)/\sigma\big)\), donde \(\Phi\) es la acumulada de la normal estándar (la que aparece en las tablas).

Usa los mismos parámetros de las curvas de arriba.

Función de supervivencia

$$S(x) = P(X \ge x) = 1 - F(x) = \frac{1}{2}\left[1 - \operatorname{erf}\!\left(\frac{x-\mu}{\sqrt{2}\,\sigma}\right)\right].$$

Función de riesgo

$$h(x) = \frac{f(x)}{S(x)} = \frac{\sqrt{2}\; e^{-\frac{(x-\mu)^2}{2\sigma^2}}}{\sigma\sqrt{\pi}\left[1 - \operatorname{erf}\!\left(\frac{x-\mu}{\sqrt{2}\,\sigma}\right)\right]}.$$

La función de riesgo de la normal es creciente. Para valores grandes de \(x\) es difícil de calcular directamente, porque tanto \(f(x)\) como \(S(x)\) se vuelven muy pequeños y su cociente pierde precisión. La solución habitual es trabajar en escala logarítmica, como se muestra en el código al final. La función de riesgo acumulado, \(H(x) = -\ln S(x)\), no tiene una expresión cerrada manejable.

Función cuantil

$$F^{-1}(u) = \mu + \sigma\sqrt{2}\,\operatorname{erf}^{-1}(2u - 1), \qquad 0 < u < 1.$$

La mediana y la moda coinciden con la media: las tres valen \(\mu\).

Funciones generadoras

La función generadora de momentos y la función característica son

$$M(t) = E\!\left[e^{tX}\right] = e^{\mu t + \sigma^2 t^2/2}, \qquad -\infty < t < \infty,$$ $$\varphi(t) = E\!\left[e^{itX}\right] = e^{i\mu t - \sigma^2 t^2/2}, \qquad -\infty < t < \infty.$$

Como la curtosis de la normal es 3, muchos programas informan el exceso de curtosis (curtosis − 3), que vale 0 para la normal y sirve como referencia para comparar otras distribuciones.

Usos

La normal se usa para modelar variables como la estatura de adultos, el peso de recién nacidos o el diámetro de piezas fabricadas, como rodamientos. Su importancia se explica por el teorema central del límite: una variable que puede pensarse como la suma de muchas variables aleatorias independientes tiende a tener distribución aproximadamente normal. Por eso también es la base de gran parte de la inferencia estadística, como los intervalos de confianza y las pruebas de hipótesis para medias.

También sirve para aproximar otras distribuciones. La binomial se aproxima bien por una normal cuando \(n\) es grande y \(p\) está cerca de 1/2. La Poisson se aproxima bien cuando su media es grande: \(\mu > 10\) da una buena aproximación y \(\mu > 20\) una mejor. En ambos casos conviene usar la corrección por continuidad, porque se aproxima una variable discreta con una continua.

En R y Python

Ojo con la parametrización: tanto R como scipy usan la desviación estándar \(\sigma\), no la varianza \(\sigma^2\).

# X ~ N(3, 4): mu = 3, sigma = 2
dnorm(4, mean = 3, sd = 2)                       # f(4)
pnorm(4, mean = 3, sd = 2)                       # F(4) = P(X <= 4)
pnorm(4, mean = 3, sd = 2, lower.tail = FALSE)   # S(4) = P(X >= 4)
qnorm(0.95, mean = 3, sd = 2)                    # cuantil 0,95
rnorm(100, mean = 3, sd = 2)                     # 100 valores simulados

# P(2 < X < 4)
pnorm(4, 3, 2) - pnorm(2, 3, 2)

# Función de riesgo estable en escala logarítmica
h <- function(x, mu, sigma) {
  exp(dnorm(x, mu, sigma, log = TRUE) -
      pnorm(x, mu, sigma, lower.tail = FALSE, log.p = TRUE))
}
h(40, 0, 1)
import numpy as np
from scipy.stats import norm

# X ~ N(3, 4): loc = mu = 3, scale = sigma = 2
X = norm(loc=3, scale=2)
X.pdf(4)          # f(4)
X.cdf(4)          # F(4) = P(X <= 4)
X.sf(4)           # S(4) = P(X >= 4)
X.ppf(0.95)       # cuantil 0,95
X.rvs(size=100)   # 100 valores simulados

# P(2 < X < 4)
X.cdf(4) - X.cdf(2)

# Función de riesgo estable en escala logarítmica
def h(x, mu, sigma):
    return np.exp(norm.logpdf(x, mu, sigma) - norm.logsf(x, mu, sigma))

h(40, 0, 1)
